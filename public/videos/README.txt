===================================================================
LUXORA ESTATES - HERO CINEMATIC BACKGROUND VIDEO DIRECTORY
===================================================================

To add your own background video:
1. Place your video file inside this folder (`/public/videos/`).
2. Name it exactly:
   `hero-background.mp4`
3. Supported formats: MP4 (H.264 / AAC for maximum web compatibility across Chrome, Safari, Edge, Firefox, and iOS/Android).
4. The website will automatically detect the video and play it with:
   - Full viewport cover
   - Muted autoplay
   - Infinite loop
   - Mobile inline playback (`playsInline`)
   - Dark cinematic gradient overlay
   - Interactive Play / Pause toggle controls on the bottom-right of the hero

Fallback behavior:
Until `hero-background.mp4` is placed here, the website automatically displays
a luxury dark-gold cinematic architectural backdrop with an interactive slot badge.
No console errors or broken elements will ever appear.
